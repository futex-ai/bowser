# Bowser

These pages define the protocol contract for the Bowser Chrome control library
and CLI. The specification is split into focused pages so browser behavior,
configuration, serialization, and the command surface can evolve without one
monolithic document.

The managed-product pages define the agreed future contract for the active
API-first product plan. Existing local-library and CLI pages remain the current
runtime contract until each managed milestone is implemented.
